# SecureSpace — EXP 3

A working React + Vite authentication demonstration. It includes validated login, a persistent one-hour local session, protected dashboard content, logout, and responsive styling.

## Run

```bash
npm install
npm run dev
```

Use `admin` / `1234` to sign in.

> This is a front-end learning demo. In a production app, authentication and token signing must be handled by a secure backend; never keep credentials or signing secrets in browser code.
